# Webnovel Helper 插件

一个用于批量创建并定时发布章节的浏览器扩展。支持从插件内置 `data/*.html` 读取内容，自动填入标题与正文，点击 Publish，设置定时（两种策略），并按规则为正文拼接前后缀文案。

## 功能总览

- 一键批量：从起始文件到终止文件（如 `1_p2.html` → `3_p2.html`）依次处理
- 标题/正文自动填充：
  - 以 HTML 的首行（或第一个非空块）作为标题，剩余内容为正文
  - 自动清理 `<script>/<style>` 与内联 `on*` 事件，避免 CSP 报错
  - 优先使用 TinyMCE API（`setContent`）注入，确保发布不为空
  - 将光标移动到末尾并自动换行
- 发布流程自动化：
  - 只点击一次“CREATE CHAPTER”进入编辑页
  - 点击顶部 Publish，等待面板稳定
  - 设置定时并确认（日期/时间输入、Enter 与“全局 Enter”）
  - 点击确认按钮（含 `span.fvsc`=confirm 的优先匹配）
- 定时策略（二选一）
  - 黄金发布窗口定时（默认）：按周时间表自动滚动到下一档发布窗口
  - 固定时间发布定时：第一篇用用户输入的时间；后续每日 +1 天，时分不变
- 前后缀拼接（可开关）：
  - 前缀：仅前 20% 章节添加
  - 后缀：
    - 每 50 章使用“急迫”后缀
    - 最后 30 章使用“社群”后缀
    - 其余使用“基础”后缀
  - 前后缀按原多行格式输出，行内全部 `<strong>` 加粗
  - `[你的Patreon链接]/[Patreon链接]` 会被替换为插件弹窗中填写的地址

## 安装

1. Chrome 打开 扩展程序 → 开发者模式
2. 选择“加载已解压的扩展程序”
3. 选中项目根目录 `webnovel/`

## 使用

1. 在 `webnovel/data/` 放置要发布的 HTML 文件，例如 `1_p2.html`、`2_p2.html` ...
2. 打开目标网站的创作/发布页面
3. 点击扩展图标，按需配置：
   - 起始/终止文件名（默认 `1_p2` → `3_p2`）
   - 初始时间（`YYYY/MM/DD HH:mm`）
   - 定时策略：
     - 黄金发布窗口（默认）
     - 固定时间发布
   - 前后缀选项：
     - 使用标准前后缀（默认）
     - 不使用前后缀
   - 当选择“使用标准前后缀”时，还需填写：
     - 你的 Patreon 地址（默认 `https://www.patreon.com/webnovel`）
     - 当前章节（默认 `1`）
     - 总章节数（默认 `200`）
4. 点击“开始流程”，插件将：
   - 依次读取 `data/{name}.html`
   - 填入标题与正文 → 点击 Publish → 设置定时 → 确认
   - 进入下一条直至结束
5. 可随时点击“停止流程”终止

## 定时策略说明

- 黄金发布窗口定时（默认）
  - 使用内置的每周黄金窗口（周一到周日），例如：
    - 周一：21:30、23:45
    - 周三：09:00、22:15、次日 00:30
    - 周五：11:45、22:00、次日 00:00
    - 周六：22:30；周日：21:00
  - 以“初始时间”为参考，匹配“最近不早于它”的下一档窗口作为第一篇定时；每发布一篇，自动滚动到下一档
- 固定时间发布定时
  - 第一篇使用“初始时间”
  - 后续每篇日期 +1 天；时分保持与第一篇相同

## 前后缀拼接规则

- 开启“使用标准前后缀”后：
  - 前缀：前 20% 章节添加
  - 后缀选择：
    - 当前章节 % 50 == 0 → 急迫型
    - 当前章节 > 总章节数 - 30 → 社群型
    - 其它 → 基础型
  - 所有前后缀会按多行转为：一行一个段落，每行整体 `<strong>` 加粗；空行保留为 `<p><br></p>`
  - `[你的Patreon链接]/[Patreon链接]` 被替换为弹窗填写的地址

## HTML 读取与标题规则

- 从 `data/{name}.html` 读取原始 HTML
- 提取标题：
  - 优先取首个非空的块级行（h1/h2/h3/p/li/div 或首行文本）
  - 标题长度上限 200 字符
- 正文：去除首行后剩余内容

## 兼容性与安全

- TinyMCE 优先 API 注入，保证发布端读取到的不是空值
- CSP 兼容：自动移除脚本与内联事件，避免“Refused to execute inline script”
- 点击事件使用鼠标/指针事件序列与 elementFromPoint，提升命中率

## 常见问题（FAQ）

- 发布报“Content cannot be empty!”
  - 已通过 TinyMCE `setContent` + `input/change/save` 修复；若仍出现，请刷新页面后重试
- 时间输入后被恢复成默认值
  - 已通过“页面级 Enter”与点击 `.ant-picker` 区域触发受控确认；仍异常时可适配为日期面板点选模式
- 未匹配到 Publish 或 Confirm 按钮
  - 页面结构存在差异，请提供按钮 HTML 片段，我们会补充选择器

## 开发提示

- 可调整黄金窗口表 `weeklyWindows` 以自定义周计划
- 若目标站点 TinyMCE 实例在 iframe，脚本已自动尝试跨 iframe 定位
- 如需正文也加粗或仅加粗部分段落，可在 `applyPrefixSuffix()` 中扩展
